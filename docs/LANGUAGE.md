# Crema 言語リファレンス

## 1. 実行モデル

Crema のプログラムは、空白で区切られたトークンを左から順に実行します。

- **リテラル** (数値・文字列・`true`/`false`/`nil`・クォート) は、データスタックに積まれます。
- **ワード** は、スタックから引数を取り出し、結果をスタックに積みます。

```crema
2 3 4 * +    # 2 + (3 * 4) = 14
```

このドキュメントでは、ワードの入出力を **スタック効果** `( 入力 -- 出力 )` で表します。
右端がスタックのトップです。たとえば `-` は `( a b -- a-b )` です。

## 2. 字句

| 要素 | 例 | 説明 |
| --- | --- | --- |
| 整数 | `42` `-7` `0xFF` | 任意精度 |
| 浮動小数点数 | `3.14` `-0.5` `1e10` `.5` | |
| 文字列 | `"hello\n"` | エスケープ: `\n` `\t` `\r` `\0` `\e` `\\` `\"` `\'` `\uXXXX`。改行を含めてもよい |
| 真偽値・nil | `true` `false` `nil` | |
| クォート | `[ 1 + ]` | 実行を遅らせたコード片。第一級の値 |
| リスト構築 | `{ 1 2 3 }` | `{` と `}` の間で積まれた値をリストにまとめる |
| 行コメント | `# ...` | トークンの先頭にある `#` から行末まで |
| 括弧コメント | `( a b -- c )` | `(` の直後が空白のとき、対応する `)` まで。入れ子にできる |
| ワード | `dup` `+` `file-exists?` | 上記以外の、空白を含まない文字の並び |

`[` `]` `{` `}` は、空白で区切らなくてもトークンになります (`[1 +]` と書けます)。

## 3. 値と型

| 型 (`type` の結果) | 説明 |
| --- | --- |
| `int` | 整数 (任意精度) |
| `float` | 倍精度浮動小数点数 |
| `string` | 文字列 (不変) |
| `bool` | `true` / `false` |
| `nil` | 値がないことを表す |
| `list` | リスト (可変) |
| `dict` | 辞書 (可変)。キーには文字列・数値・真偽値・nil を使える |
| `quote` | クォート。作られた場所の変数を捕捉する (クロージャ) |

**真偽の判定**: `false`、`nil`、`0`、`0.0` を偽とし、それ以外 (空文字列や空リストも含む) はすべて真とします。

**リストと辞書は参照で共有されます。** `dup` したり変数に入れたりしても複製は作られません。
`append` や `put` はその場で書き換え、同じリストを返します。独立したコピーが必要なときは `copy` を使います。

## 4. 関数定義

```crema
: 名前 ( スタック効果のコメント ) 本体 ;
```

- 定義はトップレベルにのみ書けます (クォートの中には書けません)。
- 同じファイル内の定義は実行前にまとめて登録されるため、定義より前の行から呼び出すことも、相互再帰も可能です。
- 名前は、変数 → ユーザー定義関数 → 組み込みワード の順に解決されます。組み込みワードと同じ名前で関数を定義すると、組み込みワードを上書きします。
- 関数の末尾で行う呼び出し (`if`/`when` の分岐の末尾も含む) は末尾呼び出し最適化されるので、末尾再帰は無限に続けられます。
- 末尾でない再帰も、制御スタックの深さ 1,000,000 まで実行できます。

```crema
: even? dup 0 = [ drop true ] [ 1 - odd? ] if ;
: odd?  dup 0 = [ drop false ] [ 1 - even? ] if ;
100001 odd? print   # true
```

## 5. 変数

```crema
-> x             # スタックのトップを取り出して x に束縛する
-> { a b c }     # 3 つ取り出して束縛する (c がトップ)。 1 2 3 -> { a b c } で a=1 b=2 c=3
x                # x の値を積む
x 1 + -> x       # 再代入
```

- 関数を呼び出すたびに新しいスコープが作られます。関数内で束縛した変数はその呼び出しのローカル変数です。
- トップレベルで束縛した変数はグローバル変数で、どの関数からも読めます。
- 関数の中で `-> x` と書くと、同名のグローバル変数があっても、常にローカル変数を作ります。
- クォートは、作られたスコープを捕捉します。そのためクォート内の `-> x` は、外側の関数のローカル変数を書き換えます。

```crema
: adder ( n -- quote ) -> n [ n + ] ;
5 adder -> add5
10 add5 call print   # 15
```

`'name` は `[ name ]` の省略形です (`{ 1 2 3 } 'square map`)。

## 6. 制御構造

| ワード | スタック効果 | 説明 |
| --- | --- | --- |
| `call` | `( q -- ... )` | クォートを実行する |
| `if` | `( cond [t] [f] -- ... )` | cond が真なら t、偽なら f を実行する |
| `when` | `( cond [t] -- ... )` | cond が真なら t を実行する |
| `unless` | `( cond [f] -- ... )` | cond が偽なら f を実行する |
| `while` | `( [cond] [body] -- )` | cond を実行して結果が真の間、body を繰り返す |
| `loop` | `( [body] -- )` | `break` するまで body を繰り返す |
| `times` | `( n [body] -- )` | body を n 回繰り返す |
| `for` | `( from to [body] -- )` | i = from … to (**to を含む**) について、i を積んで body を実行する |
| `each` | `( seq [body] -- )` | 各要素を積んで body を実行する。辞書では `{ key value }` が積まれる |
| `map` | `( seq [f] -- list )` | 各要素に f を適用したリストを作る |
| `filter` | `( seq [pred] -- list )` | pred が真を返した要素だけのリストを作る |
| `fold` | `( seq init [f] -- acc )` | f は `( acc x -- acc )` |
| `sort-by` | `( list [key] -- list )` | key の結果で安定ソートする |
| `dip` | `( x [q] -- ... x )` | x を一時退避して q を実行し、x を戻す |
| `keep` | `( x [q] -- ... x )` | x を q に渡して実行し、あとで x を積み直す |
| `break` | `( -- )` | もっとも内側のループを抜ける (関数をまたいでは抜けられない) |
| `return` | `( -- )` | 現在の関数から戻る。スタックの内容はそのまま残る |

`seq` には、リスト・文字列 (1 文字ずつ)・辞書を渡せます。

## 7. エラー処理

| ワード | スタック効果 | 説明 |
| --- | --- | --- |
| `try` | `( [body] [handler] -- ... )` | body でエラーが起きると、エラーメッセージ (文字列) を積んで handler を実行する |
| `error` | `( msg -- )` | エラーを投げる |
| `assert` | `( cond msg -- )` | cond が偽ならエラーを投げる |

エラーが起きると、スタックは `try` を開始した時点の深さまで切り詰められ、その上にメッセージが積まれます。
組み込みワードのエラー (ゼロ除算、範囲外アクセス、ファイルが無いなど) も捕まえられます。

```crema
[ "data.txt" read-file ] [ "failed: " swap + print "" ] try
```

## 9. 文法 (EBNF)

```ebnf
program    = { toplevel } ;
toplevel   = definition | item ;
definition = ":" name { item } ";" ;
item       = number | string | "true" | "false" | "nil"
           | quote | list | binding | "'" name | word ;
quote      = "[" { item } "]" ;
list       = "{" { item } "}" ;
binding    = "->" ( name | "{" { name } "}" ) ;
```
